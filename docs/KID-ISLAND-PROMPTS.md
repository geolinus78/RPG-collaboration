# Copy-And-Paste Island Prompts

Each child pastes their matching prompt into Codex while working in their own clone. The files already contain starter worlds, so the child can either keep parts they like or redesign everything except the permanent `id` and required boat.

## Emma's Prompt

```text
Help me design Emma Island in our Island Quest game. Work only in game/islands/emma-island.js. Do not edit the registry, schema, shared map engine, main.js, HTML, CSS, or another child's island file. Keep the id "emma-island" unchanged and keep exactly one reachable landmark with kind "boat" so players can travel.

My island theme is [THEME]. I want players to discover [STORY IDEA], and I want the colors and mood to feel [COLORS AND MOOD]. Make the isometric tiled island rich but playable by changing terrain, palette, atmosphere, nature, landmarks, creatures, and story. Spread interesting places across the island, keep playerStart safely on land, and put the boat somewhere the player can discover by exploring.

Read docs/KID-ISLAND-GUIDE.md and game/islands/island-schema.js. Run node scripts/validate-islands.mjs, start the game, choose Emma Island, test movement and every landmark, verify that the boat opens the sailing chooser, then commit only game/islands/emma-island.js and push branch island-emma. Summarize the island when finished.
```
