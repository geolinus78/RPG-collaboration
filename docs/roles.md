# Team Roles

Each child is the world director for one island. Within their own file they can take all of these roles:

- **World builder:** terrain seed, island shape, mountains, and nature
- **Art director:** palette, sky, fog, lighting, and landmark colors
- **Creature designer:** creature kinds, names, colors, and positions
- **Story designer:** arrival text, goal, secret, and landmark discoveries
- **Playtester:** checks that the starting point and discoveries are reachable

The adult is the integrator: review branches, run the validator, merge one island at a time, then play all four tabs.
