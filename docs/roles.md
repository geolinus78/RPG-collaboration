# Team Roles

Kids can work alone, in pairs, or in small teams. Rotate roles between sessions so everyone gets to try different parts of game making.

## Story Team

Owns:

- Character names
- Dialogue
- Signs
- World lore

Main file: `game/data/dialogue.js`

## Map Team

Owns:

- Tile layout
- NPC positions
- Item positions
- New areas

Main file: `game/data/world.js`

## Quest Team

Owns:

- Quest goals
- Checklist steps
- Rewards
- Win conditions

Main file: `game/data/quests.js`

## Art Team

Owns:

- Player art
- NPC art
- Tile art
- Item art

Main folder: `game/assets/art/`

## Sound Team

Owns:

- Sound effect ideas
- Music ideas
- Audio files

Main folder: `game/assets/audio/`

## Code Team

Owns:

- Movement rules
- Buttons
- Keyboard controls
- New game systems

Main files: `game/src/main.js` and `game/styles.css`

## Session Lead

The session lead helps the group decide what goes into the game today. This role can rotate each meeting.

Responsibilities:

- Pick 3 to 5 tasks from `TEAM_BOARD.md`.
- Make sure everyone knows which file they are editing.
- Run a final playtest.
- Help write a short summary of what changed.
